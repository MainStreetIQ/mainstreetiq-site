Platform + Practice

What We Use From Anthropic, and What We Build Ourselves

Manage runs on Anthropic's generally-available Claude products, used on commercial API terms. The practice layer on top is built by Main Street IQ. Honest about which is which.

What we use from Anthropic

Generally-available Claude products, configured for your engagement:

  • Claude Messages API. The inference layer for every skill output, used on Anthropic's commercial API terms. Zero Data Retention is available for this API as a per-organization arrangement through Anthropic's sales team; it is not yet in place for Main Street IQ.
  • Claude Code. Anthropic's agentic tool for code and automation. Our skills run inside it and call the Messages API directly.
  • Claude Cowork. Anthropic's collaborative writing surface ($20/mo per seat). Where Scott and your team draft monthly close narratives, board decks, and lender packages with Claude as a real-time collaborator.
  • Claude for Excel. The Microsoft Excel add-in ($20/mo per seat). Where your CEO and growth team edit driver-based forecasts and scenario models live, with Claude tracing references across tabs and diagnosing model structure.
  • Claude on AWS Bedrock with PrivateLink (enterprise add-on). Available for clients who require network-isolated deployment and have an existing AWS posture. Not the default; scoped per engagement.

Cowork and Claude for Excel are not currently ZDR-eligible by Anthropic's policy. We use them transparently for collaborative work; high-sensitivity flows run on the Messages API.

What we build ourselves

The practice and security layers on top:

  • Credential broker. A local secrets store built by Main Street IQ, backed by the operating system keychain, that mints short-lived, narrowly scoped tokens one call at a time. Version one is built and tested against mock providers; live provider connections come next. Our rule in the meantime: no credential reaches a model in any form.
  • De-identification before AI. Our handling is designed so models work from aggregates and de-identified data rather than raw customer records. Customer identifiers are replaced with keys and leak-checked, and a guard blocks AI tools from reading raw client exports.
  • Per-client read scoping and structured audit log. A scoping layer stops a run for one client from reading another client's folder. Month-end close, P&L, P&L forecast and finance package runs append a structured audit entry to that client's folder, available to you on request.
  • Vertical-specific skills. Marketplace settlement reconciliation, cohort economics with long-window variants, marketing halo attribution, multi-location inventory, 3PL invoice forensics, cash-forecast drift detection.
  • Four market-segment packs. Ecommerce, wine, health and wellness, elective medicine. Different stacks, different cohort definitions, different compliance calendars.
  • Per-client CEO dashboard. Four tiers, phone-first, with the disclosure tier discipline (real / benchmark / fixture) we ship on every artifact.
  • The pre-publish gate. Every artifact that leaves the engagement is checked for canonical facts, scope, voice, factual accuracy, legal and regulatory risk, and the numbers behind it. Plus Scott signs every monthly close.
The Six Controls

Three From Anthropic. Three From Us.

Every embedded finance engagement should be able to name its security controls specifically. Here are ours, and where each one stands today.

Zero Data Retention: Where It Stands

The Claude Messages API is eligible for Zero Data Retention under Anthropic's published policy: prompts and outputs are not stored at rest after the response returns. The arrangement is per-organization and provisioned through Anthropic's sales team. It is not yet in place for Main Street IQ. If your engagement requires it, ask us where it stands.

No Training on Your Data

Anthropic does not train on commercial API customer data. This is contractual under the API terms of service and applies independently of ZDR.

Optional PrivateLink via AWS Bedrock

For enterprise clients requiring network-isolated inference, we can deploy Claude on AWS Bedrock with PrivateLink. Your queries route through your own AWS VPC; financial data does not transit the public internet. Added as a scoped per-engagement option, not the default. See pricing and architecture spec on request.

Main Street IQ Credential Broker

A local secrets store built by Main Street IQ, backed by the operating system keychain, holds long-lived provider credentials and mints short-lived, narrowly scoped tokens one call at a time. Version one is built and tested against mock providers; live connections to QuickBooks and other providers come next. Our rule in the meantime: no credential reaches a model in any form.

De-identification + Client Scope

Our handling is designed so models see aggregates or de-identified data rather than raw rows: customer identifiers are replaced with keys and leak-checked, and a guard blocks AI tools from reading raw client exports. A scoping layer stops a run for one client from reading another client's folder.

Audit Log + Pre-Publish Gate

Month-end close, P&L, P&L forecast and finance package runs append a structured audit entry to that client's folder, available to you on request. Every artifact bound for outside our engagement (CPA, lender, board) passes through an integrity gate that checks facts, scope, voice, legal and regulatory risk, and the numbers.

Claude Cowork and Claude for Excel, which we use for collaborative document work, are not currently ZDR-eligible by Anthropic's published policy. We disclose this transparently and route high-sensitivity flows through the Messages API path.

Regulated Engagements

HIPAA Requirements and Data Residency

HIPAA. For elective medicine clients handling protected health information, an engagement requires a signed Business Associate Agreement and a HIPAA-enabled setup on whichever platform runs the work: on Anthropic's own API, HIPAA readiness is enabled at the organization level; on AWS Bedrock, coverage comes through AWS's own BAA. Ask us where that stands before sharing any PHI.

Data residency. Standard engagements process data in US-based Anthropic infrastructure. Bedrock-deployed clients choose their AWS region directly.

Subprocessor list. Our full subprocessor list is maintained at our Privacy page and updated whenever we add or change a vendor.

For The Buyer Who Probes

A Note On Claude for Financial Services

Anthropic released "Claude for Financial Services" on May 5, 2026. It is a product for institutional finance firms: Citadel, Carlyle, BNY, Travelers, Walleye Capital, Hg. It ships ten agent templates designed for investment banking workflows (pitchbook construction, KYC screening, model building, earnings review) and a set of data-partner integrations (FactSet, S&P Capital IQ, MSCI, PitchBook).

Manage does not use that product. The institutional-FS agent templates are not designed for lower middle market finance and the data-partner integrations are not relevant for the buyer we serve. We use the underlying generally-available Claude products (the Messages API, Claude Code, Cowork, Excel) directly. If a security team asks whether Main Street IQ is "on the same platform as Citadel," the answer is honest: same Anthropic platform underneath, very different product surface on top.
